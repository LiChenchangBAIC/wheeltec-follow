## arm_demo功能包说明
arm_demo功能包是基于MoveIt2的机械臂运动控制演示功能包，提供了多种典型的机械臂运动控制示例，帮助用户快速了解和掌握机械臂的编程控制方法。
* 1.功能包使用。
* 2.功能包架构说明。
* 3.示例代码说明。  
通过这三部分内容的介绍可以帮助大家：
* 1.了解该功能包的使用方法。
* 2.熟悉功能包中的文件构成及作用。
* 3.掌握基于MoveIt2的机械臂编程控制方法。

## arm_demo功能包使用

### 正运动学演示
正运动学演示程序展示了如何通过设置关节角度来控制机械臂运动。首先确保机械臂已正确连接并启动了MoveIt2，然后运行以下命令：
```
$ ros2 launch arm_demo fk_demo.launch.py
```
该程序将控制机械臂各关节运动到指定角度位置。

### 逆运动学演示
逆运动学演示程序展示了如何通过设置末端位姿来控制机械臂运动。运行以下命令：
```
$ ros2 launch arm_demo ik_demo.launch.py
```
该程序将根据指定的末端位姿计算关节角度并控制机械臂运动。

### 圆形轨迹运动
圆形轨迹运动演示程序展示了如何控制机械臂末端沿圆形轨迹运动。运行以下命令：
```
$ ros2 launch arm_demo move_circle.launch.py
```
该程序将控制机械臂末端在空间中画圆。

### 笛卡尔空间运动
笛卡尔空间运动演示程序展示了如何在笛卡尔空间进行轨迹规划。运行以下命令：
```
$ ros2 launch arm_demo moveit_cartesian.launch.py
```
该程序将演示机械臂在笛卡尔空间的直线运动。

## 示例代码说明

### 正运动学控制（fk_demo）
正运动学控制通过直接设置机械臂各关节的角度来控制机械臂运动到目标位置。适用于已知关节角度的场景。

### 逆运动学控制（ik_demo）
逆运动学控制通过设置机械臂末端执行器的目标位姿（位置和姿态），由系统自动计算所需的关节角度。适用于已知末端位姿的场景。

### 轨迹规划控制（move_circle/moveit_cartesian）
轨迹规划控制可以让机械臂末端按照预定的路径运动，支持圆形、直线等多种轨迹类型。

## 依赖说明
该功能包依赖以下ROS2功能包：
- rclcpp：ROS2 C++客户端库
- moveit_ros_planning_interface：MoveIt2规划接口
- moveit_common：MoveIt2公共库

## 使用建议
1. 在运行演示程序前，请确保已正确启动机械臂驱动和MoveIt2节点
2. 建议先在RViz中观察规划结果，确认无误后再执行
3. 首次使用时建议降低机械臂运动速度，逐步熟悉控制方法
4. 可以参考示例代码进行二次开发，实现自定义运动控制功能
