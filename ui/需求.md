# 界面需求

主界面是一张 HTML 页面。视觉以 `设计稿/hmi-18-status.jpg` 为定稿，其后补上右上角登录。车上其余传感器、话题和功能不单独展示。

另一位工程师在另一条主线上做语音控车，源码不在本仓库。界面不实现语音识别，只显示声纹和最近一条指令。

## 1. 页面

界面用浏览器打开，版式锁定 16:9。窗口变宽或变高时，整页按比例缩进当前窗口，一块屏幕看完，不出现页面滚动条。窗口比 16:9 更宽或更高时，多出来的区域留空，不把画面拉变形。

页面底用界面自己的深色渐变。摄像头画质低，不铺满当背景，只出现在「车辆视觉」的窗口里。

卡片为毛玻璃，数字大，点缀色用珊瑚橙。状态灯只用绿和红：绿是正常，红是不正常。

顶栏左侧是北汽红色字标，用 `设计稿/baic-logo.png`，尺寸小，周围留白。右侧是用户头像和名字。未登录时名字为「未登录」，登录成功后改为所填用户名。

## 2. 登录

点击右上角头像，弹出登录窗口。窗口里有主机、用户名、密码。

- 登录成功后，左侧「已连接」变为绿灯。
- 未登录时，这盏灯为红色，文字是「未连接」。
- 登录成功后窗口不自动关闭，由用户点「关闭」收起。收起后登录状态保留。
- 退出后回到未登录，连接灯恢复红色。

接入小车之前，登录是界面内的仿真校验：填了用户名和密码即视为成功，还不会真正连到车上。

## 3. 车辆基本信息

这一块在左侧，含车速、电量、两盏状态灯，以及语音显示。

| 显示 | 含义 |
| --- | --- |
| 车速 | 车当前开得多快。数据来自里程计话题 `odom` 里的行驶速度。未连接时不显示数值。 |
| 电量 | 底盘上报的电源电压，话题 `PowerVoltage`，单位伏。界面显示电压，不换算成百分比。未连接时不显示数值。 |
| 已连接 | 和登录状态一致。绿灯为已连接，红灯为未连接。 |
| 功能正常 | 和「已连接」同一排，前面也有一盏灯。不拆成每个传感器一行。 |

「功能正常」覆盖本界面用到的这些项：底盘、相机、超声波、SLAM（定位与地图）、目标检测与尾随、定点导航、语音状态。

- 全部正常时，只显示「功能正常」，灯为绿色。
- 有一项不正常时，仍然是这一个要素，灯改为红色，并写出不正常的那一项名称。
- 尚未连接时，车端是否正常无法判断，这盏灯为红色，文字为「无法确认」。

这一排和上方的电量之间留出明显行距。

语音放在这一块下方，不单独占一块面板：

- 用声纹波动效表示正在听，不写「正在监听」或同类四个字。
- 声纹下方只显示最近收到的一条指令。
- 不堆历史对话。

## 4. 车辆视觉

显示车辆前方 RGB 相机的画面，比例约 16:9。画面上标出检测到的物体和标签。用户在这块里选定要尾随的目标。

交互沿用已经在车上做过的点选尾随（`yolo_same_follow`）：

- 在画面上点一个物体，车只跟随这一个跟踪目标。
- 选定之后不自行换成别的物体。
- 目标编号消失，或用户取消锁定，车停下，直到下一次点选。

这块收进主界面，不再单独开一个页面。画面向上收，下面让给控制台。

## 5. 周围环境俯视图

用 SLAM 重建周围环境的顶视图，近处障碍叠上超声波。

- 用户在图上选定终点。A 是车当前的位置，B 是点下去的那个点。
- 选定后，车从 A 自主开到 B。
- 用户不在这张图上再指定起点。

## 6. 控制台

位于车辆视觉下方，用来用命令和机器人交互。

- 标题为「控制台」。
- 标题旁有一排标签，收纳已经打开的会话，并有新建会话的按钮。
- 多个会话可以并存，各自记住自己的输入和输出。
- 正文字体要小，一块里能放下多行命令。命令多出窗口时，只在控制台内部滚动，不带动整页。

## 7. 不进主界面的内容

键盘遥控、机械臂、巡线、雷达跟随，以及功能清单里其余算法，都不在这张主界面上单独显示或操作。以后要加，再改这份需求。
