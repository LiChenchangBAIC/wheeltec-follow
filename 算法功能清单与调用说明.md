# Wheeltec 算法功能清单与调用说明

> 设备：`192.168.0.105`（主机名 `wheeltec`，ROS 2 Humble / Jetson）  
> 本地源码：`algorithm/`（仅算法代码与配置，已跳过语音资源包、模型权重、网格等大文件）  
> 原始指令底稿：`algorithm/wheeltec_ros2/src/ROS2-V6.0(humble)常用指令.txt`、`ROS2-3D_Slam(humble)常用指令.txt`

---

## 1. 使用前准备

在设备上（SSH 或网页控制台）：

```bash
ssh wheeltec@192.168.0.105


cd ~/wheeltec_ros2
source /opt/ros/humble/setup.bash
source install/setup.bash
```

本机入口：


| 用途         | 路径                                                |
| ---------- | ------------------------------------------------- |
| WebSSH 登录页 | `wheeltec-console.html` → `http://127.0.0.1:8787` |
| 算法源码目录     | `algorithm/`                                      |
| 同步进度页      | `http://127.0.0.1:8790/progress.html`             |


编译（改 launch 后）：

```bash
cd ~/wheeltec_ros2
colcon build --symlink-install
# 或单包：
colcon build --packages-select turn_on_wheeltec_robot --symlink-install
```

## 2. 本地 `algorithm/` 目录结构


| 目录                                | 内容                                                 | 约大小    |
| --------------------------------- | -------------------------------------------------- | ------ |
| `algorithm/wheeltec_ros2/src/`    | 主车算法（导航/SLAM/跟随/感知等）                               | ~24MB  |
| `algorithm/autoware/src/`         | Autoware 相关源码                                      | ~65MB  |
| `algorithm/wheeltec_arm/src/`     | 机械臂 / MoveIt / YOLO-TensorRT / VLM                 | ~3.4MB |
| `algorithm/wheeltec_stepper_arm/` | 步进臂相关                                              | ~2MB   |
| `algorithm/jetracer/`、`jetcam/`   | 沙盘车道保持相关                                           | 很小     |
| `algorithm/home_scripts/`         | AB 导航会话等自用脚本                                       | 很小     |
| ~~语音包~~                           | `wheeltec_mic*` / `tts*` / `bodyreader` 资源 **未拉取** | —      |


解析调用时：先看各包下的 `launch/*.launch.py`，再看 `package.xml` 里的包名（`ros2 launch <包名> <文件>`）。

## 4. 推荐最小调用链路（上手）

**遥控走车：**

```bash
ros2 launch turn_on_wheeltec_robot turn_on_wheeltec_robot.launch.py
# 新终端
ros2 run wheeltec_robot_keyboard wheeltec_keyboard
```

**建图 → 存图 → 导航：**

```bash
ros2 launch wheeltec_slam_toolbox online_async_launch.py
# 遥控转一圈后
ros2 launch wheeltec_nav2 save_map.launch.py slam_toolbox:=true
ros2 launch wheeltec_nav2 wheeltec_nav2.launch.py
```

**雷达跟随：**

```bash
ros2 launch turn_on_wheeltec_robot wheeltec_sensors.launch.py
ros2 launch simple_follower_ros2 laser_follower.launch.py
```

## 7. 说明与边界

1. **本清单面向「如何调用」**：命令来自设备自带指令文件 + 各包 launch 入口。
2. **本地** `algorithm/` **只有源码/配置**，不含 `.pt` / `.so` / 语音资源 / URDF 网格；要在车上跑视觉模型或语音，仍用设备原环境。
3. 若需补拉某个语音/模型包，可再说，单独同步即可。
4. 重新只拉算法源码：`algorithm/pull_algo_only.sh`（约 2 分钟量级）。
