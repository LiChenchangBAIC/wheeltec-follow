# Wheeltec WebSSH

浏览器端 SSH 控制台，用于登录局域网中的 Wheeltec / Jetson 设备（默认 `192.168.0.105`）。

## 启动

```bash
cd wheeltec-webssh
npm install
npm start
```

浏览器打开：http://127.0.0.1:8787

同一局域网的其他电脑，打开登录页里「同一网络门户」显示的地址（启动时也会打印在终端）。页面本身没有单独的访问密码，请只在可信网络使用。

默认账号可填：`wheeltec` / 设备密码。主机与用户名可选「记住」。

## 说明

- 密码仅经运行服务的那台电脑转发到设备 SSH，不会写入服务器文件。
- 服务监听 `0.0.0.0:8787`。其他电脑要能打开门户，运行服务的电脑须放行 8787 端口。
